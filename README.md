# ff-1204.github.io

`https://ff-1204.github.io/` 맨 위 주소용 저장소예요. `index.html`은 작업실 첫 화면이에요. 위에서부터 소개, **스킬로 만든 것**(claude-haejo · 도리의 정원), **발표한 것**(세미나 발표 자료) 순서이고, 주소 끝에 `#works`·`#talks`를 붙이면 그 구역으로 바로 가요. 검색·수집 로봇은 도메인 맨 위의 `robots.txt`만 읽어서, AI 학습용 수집 거절을 여기에 둬요. ff-1204의 모든 프로젝트 사이트(예: [도리의 정원](https://ff-1204.github.io/doris-garden/))에 함께 적용돼요.

## 프로젝트 더하기

"스킬로 만든 것" 맨 위에 [claude-haejo](https://ff-1204.github.io/claude-haejo/)를 두고, 그 스킬로 만든 프로젝트를 아래에 차례로 모아요.

- Claude Code에 "포트폴리오에 <프로젝트> 추가해줘"라고 하면 돼요.
- 직접 할 땐 `index.html`의 "스킬로 만든 것" 안에서 프로젝트(`<article class="entry">`)를 통째로 복사해(스타 링크의 `data-repo`도 저장소 이름으로) "다음 자리" 줄(`.soon`) 바로 위에 붙이고, 그림·이름·소개·주소만 바꿔요. 미리보기 그림은 1200×630(`og.png`)이 잘 맞아요.

## 발표 더하기

발표 자료는 저장소 안 폴더(예: [`kw-seminar/`](https://ff-1204.github.io/kw-seminar/))에 두고, `index.html`의 "발표한 것" 안에서 발표(`<article class="entry">`)를 통째로 복사해 바로 아래에 붙여요. 그림은 표지를 1200×630(`og.png`)으로 담으면 잘 맞아요.

공개 저장소라서 학교·회사 이름과 실명은 올리지 않아요. 발표 자료도 그 부분을 숨긴 판으로 올려요.

## 휴대폰에서 보기

- 첫 화면(`index.html`)은 폭 820px·460px에서 한 줄로 접히고, 누르는 곳은 높이 44px 이상이에요.
- 발표 자료는 좁은 화면에서 세로로 이어 보여요. 슬라이드를 누르면 그 장만 크게 보는데, 세로로 든 화면에서는 슬라이드를 옆으로 눕혀 화면을 채워요. 위아래로 밀거나 눌러서 넘기고, "목록"이나 뒤로 가기로 돌아와요. 휴대폰을 가로로 돌리면 PC처럼 한 장씩 넘겨요.
