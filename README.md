# ff-1204.github.io

`https://ff-1204.github.io/` 맨 위 주소용 저장소예요. `index.html`은 프로젝트를 모아 보여 주는 포트폴리오 페이지예요(도리의 정원 · claude-haejo). 검색·수집 로봇은 도메인 맨 위의 `robots.txt`만 읽어서, AI 학습용 수집 거절을 여기에 둬요. ff-1204의 모든 프로젝트 사이트(예: [도리의 정원](https://ff-1204.github.io/doris-garden/))에 함께 적용돼요.

## 프로젝트 더하기

맨 위에 [claude-haejo](https://ff-1204.github.io/claude-haejo/)를 두고, 그 스킬로 만든 프로젝트를 아래에 카드로 모아요.

- Claude Code에 "포트폴리오에 <프로젝트> 추가해줘"라고 하면 돼요.
- 직접 할 땐 `index.html`의 "claude-haejo로 만든 것" 안에서 프로젝트 카드(`<article class="paper card">`)를 통째로 복사해 "다음 자리" 카드 바로 위에 붙이고, 그림·이름·소개·태그·주소만 바꿔요. 미리보기 그림은 1200×630(`og.png`)이 잘 맞아요.
